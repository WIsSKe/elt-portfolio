# ELT Portfolio — Basics of English Methodology

A personal reflective portfolio for the *Basics of English Methodology* course.

## Structure

- **Journal** — 6 reflective entries (min. 100 words each) on course topics
- **Dossier** — 4 practical tasks with filed reflections

## How to view

Open `index.html` in any browser, or visit the live site at:  
`https://YOUR-USERNAME.github.io/elt-portfolio`

## How to edit

1. Open `index.html` in any text editor (VS Code, Notepad++, etc.)
2. Find the entry you want to fill in — search for `entry-placeholder`
3. Replace the placeholder text with your actual reflection
4. To mark a word count as done, change `wc-dot` to `wc-dot done`

## Deploy updates

```bash
git add .
git commit -m "Add journal entry 1"
git push
```

GitHub Pages updates automatically within ~1 minute.
